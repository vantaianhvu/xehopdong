🚀 Deploy lên GitHub PagesWeb tĩnh miễn phí, có link chia sẻ
Sau khi deploy, link dạng: https://[username].github.io/dashboard-xe/
Chỉ ai biết link mới vào được — kết hợp màn hình đăng nhập để bảo vệ nội dung.
1

Tải file HTML về máy

Nhấn nút bên dưới để tải file index.html (đã bao gồm toàn bộ dữ liệu & tài khoản hiện tại)

2

Tạo repository trên GitHub

Vào github.com/new → đặt tên repo dashboard-xe → chọn Public → nhấn Create repository

3

Upload file lên GitHub

Trong repo vừa tạo → nhấn Add file → Upload files → kéo thả file index.html vào → nhấn Commit changes

4

Bật GitHub Pages

Vào Settings → Pages → Source: chọn Deploy from a branch → Branch: main, folder /(root) → nhấn Save

5

Chờ ~1 phút → Có link!

Quay lại Settings → Pages sẽ thấy link xanh. Chia sẻ link đó — người xem phải đăng nhập mới vào được dashboard.

💡 Cập nhật dữ liệu sau này: Thêm dữ liệu trong app → Tải lại file → Upload đè lên GitHub → tự động cập nhật web.
